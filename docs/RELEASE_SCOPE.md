# Release scope and intentional exclusions

## Included

- Primary vaccination-strategy simulation code.
- Disease-parameter robustness simulation code.
- Network-structure robustness simulation code.
- Infection-timing, random-forest, SHAP, Pearson, Lasso, and threshold analyses.
- Scripts that generate the analytical panels and plotting components used in
  the manuscript and Supplementary Information.
- Workflow-specific package-version records.
- A synthetic smoke test that exercises the primary simulation code path.
- A documented schema and generator for adapting the framework to a custom
  weighted network.

## Intentionally excluded

### Household-survey data

The survey workbook is not publicly distributed because it contains
potentially sensitive participant and household information. The repository
therefore does not support exact numerical reproduction without authorized
access to the study data.

### Final multi-panel assembly files

Individual analytical panels were generated by code. Final panel assembly,
panel lettering, and minor layout adjustments were performed manually in
Microsoft PowerPoint. No automated script is provided for reproducing those
presentation-only operations.

### Figure 1 editable source

Figure 1 is a manually drawn conceptual schematic rather than a data-derived
result. Its editable source file is outside the computational reproduction
scope and is not included.

### Cluster submission scripts

The complete parameter sweeps were run using parallel computing. Scheduler
submission files are not included because they contain system-specific resource
and queue settings and do not alter the scientific calculations implemented in
the Python entry points.

### Complete synthetic replacement for the survey

The repository does not provide a synthetic dataset intended to emulate the
empirical survey distribution or reproduce manuscript estimates. The included
smoke-test data are deliberately minimal and exist only to verify execution.

## Reproduction claims

The repository supports inspection of the implemented model, parameterization,
strategy definitions, outcome calculations, and figure-generation logic. It
also supports a lightweight execution check. Exact reproduction of reported
numerical results requires the authorized survey workbook and the full
production settings.
